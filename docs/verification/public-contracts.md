# Public behavior boundaries

Source declarations in Boo.Core/Contracts.cs are the shared vocabulary. Other source files initially throw NotImplementedException so tests can prove real missing behavior before builders. Tests and builders consume these signatures; root alone changes signatures or manifests, with test-author review before a baseline revision.

- FocusSession follows the pinned Swift reference: starts running; duration 60–14400 seconds; advance uses real seconds, developer clock 4x; paused/ended never advances; pause appends a paused observation. NudgePolicy ports the exact 120–240 second strength span, 20-second age, 45-second gap and 120-second cooldown. Confidence is diagnostic, never a second probability threshold.
- RequestCoordinator.Begin invalidates/cancels the prior lease. Stop and TryCommit serialize: effects committed before Stop are accurately reported, none can begin after Stop. Dispose behaves as Stop and disallows another Begin.
- ActionPolicy requires current explicit task authority and an allowed tool name. Initial names: search, inspect, open_url, open_app, click, type_text, write_file, delete_file. Unknown names are denied. Click/type/write/delete require concrete approval in the initial conservative UI-impact policy; browser protocol launches only accept http/https. App IDs resolve through a local registry in DesktopTools. Approval digest covers immutable tool name, target, sorted argument keys/values, and generation.
- ScopedFiles accepts only relative paths rooted inside a real selected directory, rejects traversal, absolute paths, alternate streams and all reparse-point components. Revalidate before a write. DesktopTools verifies actual outcomes, never reports success because input was merely sent.
- AnnotationValidator accepts ring, arrow and label marks with finite in-frame coordinates, matching observation/generation/display and valid target; context age 0–15 seconds. MapToDisplay returns physical pixels, including negative display origins; rendering converts once to DIP. NotchBounds returns physical pixels for DIP dimensions scaled on the selected monitor.
- SessionStore persists only FocusSnapshot fields through SQLite; save upserts by ID, list returns newest first, delete affects only the supplied ID. SettingsStore uses JSON. CredentialStore uses Windows CurrentUser protection and never logs values. Missing credential loads null; corruption surfaces a sanitized actionable error. No image/audio/OCR field exists in the persistent schema.
- ResponsesClient and DecisionsClient accept injectable HttpClient for real transport-boundary fixture tests. Credentials come from the supplied delegate; never attach credentials to a non-OpenAI origin. Requests use /v1/responses and /v1/decisions and enforce cancellation and sanitized HTTP errors. Research returns source URLs from API citation annotations. Assistant result JSON uses text, marks, actions; marks contain kind,x,y,width,height,label,endX,endY; actions contain name,target,arguments. Client binds proposals to the actual submitted ScreenContext, not model-invented observation IDs.
- RealtimeProtocol operates on documented OpenAI Realtime JSON. Voice session is PCM16 mono 24kHz, server VAD, input transcription, audio output with transcript. Native audio is never stored. RealtimeClient owns connection/send/receive/interruption; voice tool calls route to the same Responses/action policy as text.

Native capture, microphone intelligibility, actual focus preservation, exclusion, accessibility and latency remain packaged-app/live cases. Protocol/geometry fixtures cannot certify those outcomes.
